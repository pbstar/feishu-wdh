# 飞书文档导出助手（feishu-wdh）

一键将当前 **飞书文档** 经 **AI 优化** 后导出为 **Markdown**，图片一并下载并打包为 ZIP。可选生成 **前端研发任务清单**。

> 文档提取与打包均在浏览器本地完成，扩展不设自有服务器、不收集任何数据；AI 优化需将文档内容发送至你配置的大模型服务。

## 功能特性

- **一键导出**：点击工具栏图标，立即导出当前文档。
- **AI 文档优化**（必开）：导出逐段精简、去冗余的 `文档标题.md`。
- **AI 前端研发任务总结**（可选）：基于需求文档自动梳理前端研发待开发任务，生成一份任务清单。
- **Markdown 输出**：生成符合 GitHub Flavored Markdown (GFM) 规范的 `.md` 文件。
- **图片本地化**：文档中的图片下载至 `images/` 目录，Markdown 使用相对路径引用。
- **ZIP 打包**：将 `.md` 文件与 `images/` 目录一同打包，压缩包以文档标题命名。
- **富文本处理**：支持标题、列表、表格、代码块、引用、加粗/斜体等常见格式。
- **断点续显**：导出过程中关闭弹窗后重新打开，自动恢复显示当前进度与上次导出结果。
- **完全本地**：导出流程在浏览器中执行，无需上传内容至扩展开发者。

## 支持的文档类型

| 类型 | 说明 |
| --- | --- |
| Docx | 飞书新版文档 |
| Wiki | 知识库文档 |
| Docs | 旧版文档 |

支持域名：`feishu.cn`、`larksuite.com`。

## 使用方法

1. 打开一个飞书文档页面。
2. 点击浏览器工具栏中的扩展图标，在弹窗中点击 **「导出 Markdown」**。
3. 等待处理完成，浏览器将自动下载 ZIP 文件。
4. 解压后即可获得 `文档标题.md` 及配套的 `images/` 目录。

> **提示**：AI 文档优化为必开功能，首次使用需在扩展设置页面完成 API 配置。导出时，文档会先发送至你指定的大模型服务进行优化，处理完毕后再生成 ZIP 文件。

## AI 文档优化（必开）与前端研发任务总结（可选）

两个功能共用同一套大模型 API 配置。

### AI 文档优化

**必开**。导出 ZIP 的**唯一主文件**为 `文档标题.md`：保留原文结构与段落顺序，逐段精简、去冗余，使表达更凝练，不丢失关键信息；必要时适度运用 Markdown 排版让文档更清晰易读。原文不直接导出，仅作为 AI 处理的输入。

### AI 前端研发任务总结

**可选**（默认关闭）。开启后，导出时在优化版之外**额外**生成一份前端研发任务清单（`文档标题-任务清单.md`）：基于需求文档按功能模块梳理前端研发待开发任务，以任务列表（`- [ ]`）精炼呈现，可直接用于研发排期。文档优化与任务清单**并行**执行，不延长导出总耗时。

### 配置项

在扩展的设置页面提供以下三项：

| 配置项 | 说明 | 示例 |
| --- | --- | --- |
| **API 地址** | 兼容 OpenAI Chat Completions 格式的接口地址 | `https://api.deepseek.com/chat/completions` |
| **API 密钥** | 访问模型服务的鉴权密钥 | `sk-xxxxxxxx` |
| **模型名称** | 使用的模型标识 | `deepseek-v4-flash` 等 |

> 兼容所有 **OpenAI Chat Completions** 风格的服务，如 OpenAI、DeepSeek、通义千问、Moonshot 等。

### 说明

- 所有配置信息保存在浏览器本地（`chrome.storage`），不上传至开发者服务器。
- 文档内容会发送至你填写的**大模型服务商**进行优化，请自行确认其隐私政策。
- 提示词由扩展内置，无需手动编写。

## 安装

### 方式一：下载压缩包安装（推荐）

1. 从项目的 [`versions/`](versions/) 目录下载最新的 `feishu-wdh-vX.X.X.zip`。
2. 解压到本地任意目录。
3. 打开 Chrome，访问 `chrome://extensions/`。
4. 打开右上角「开发者模式」。
5. 点击「加载已解压的扩展程序」，选择解压后的目录。

### 方式二：从源码构建（开发者模式）

确保已安装 Node.js，然后执行：

```bash
git clone https://github.com/pbstar/feishu-wdh.git
cd feishu-wdh
npm install
npm run build
```

构建完成后：

- `dist/` 为可加载的扩展产物。
- `versions/feishu-wdh-vX.X.X.zip` 为按当前版本号自动打包的压缩包。

加载步骤：

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择项目中的 `dist/` 目录。

> 执行 `npm run build` 即可完成 TypeScript 类型检查、构建，并自动打包为 `versions/` 压缩包。

## 技术栈

- **Manifest V3** – Chrome 扩展标准
- **Content Script** – 只读提取文档 DOM，边滚边采并就地抓图
- **自研转换器** – 结构化节点树 → GFM Markdown（`src/converter/`）
- **JSZip** – 客户端 ZIP 打包
- **Offscreen Document + chrome.downloads** – 长任务（AI 请求、生成 Blob URL）在离屏文档中执行，规避 MV3 service worker 生命周期限制；下载仍由 service worker 触发
- **Vite + @crxjs/vite-plugin** – 构建打包

## 项目结构

```
feishu-wdh/
├── src/
│   ├── content/      # 内容脚本：滚动预加载 + 只读提取文档结构 + 抓图
│   ├── converter/    # Markdown 转换逻辑
│   ├── ai/           # 大模型调用（文档优化、前端研发任务总结）
│   ├── export/       # ZIP 打包、下载
│   ├── background/   # service worker：消息路由、编排导出流程
│   ├── offscreen/    # 离屏文档：AI 请求、Blob URL 触发下载（规避 SW 生命周期限制）
│   ├── shared/       # 跨模块类型、消息、存储封装
│   ├── styles/       # 公共样式
│   └── popup/        # 扩展弹窗 UI（含 AI 配置设置视图）
├── public/
│   └── icons/        # 扩展图标
├── scripts/
│   └── pack.mjs      # 构建后将 dist 打包为 versions/*.zip
├── src/manifest.config.ts # 扩展清单（TS 形式）
├── versions/         # 各版本打包产物（.zip）
└── dist/             # 构建产物
```

## 隐私说明

- 本扩展不包含自有服务器，**不会收集、留存任何用户数据**，亦不出售用户信息。
- 文档的提取与图片下载均在本地浏览器中完成。
- AI 文档优化为必开功能：文档内容会发送给你自行配置的第三方大模型服务进行优化，该部分数据的处理受该服务商的隐私政策约束。
- 若开启「AI 前端研发任务总结」，文档内容还会发送给同一大模型服务生成任务清单。
