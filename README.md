# 飞书文档导出助手（feishu-wdh）

一键将当前 **飞书 / Lark 文档** 转换为 **Markdown**，图片一并下载并打包为 ZIP。可选接入大模型，在导出前对内容进行 **AI 总结精简**。

> 所有处理均在浏览器本地完成，扩展不设自有服务器、不收集任何数据。

## 功能特性

- **一键导出**：点击工具栏图标，立即导出当前文档。
- **AI 总结精简**（可选）：导出前调用大模型对文档进行总结、压缩，长文提炼要点、去除冗余一步到位。
- **Markdown 输出**：生成符合 GitHub Flavored Markdown (GFM) 规范的 `.md` 文件。
- **图片本地化**：文档中的图片下载至 `images/` 目录，Markdown 使用相对路径引用。
- **ZIP 打包**：将 `.md` 文件与 `images/` 目录一同打包，压缩包以文档标题命名。
- **富文本处理**：支持标题、列表、表格、代码块、引用、加粗/斜体等常见格式。
- **完全本地**：导出流程在浏览器中执行，无需上传内容至扩展开发者。

## 支持的文档类型

| 类型 | 说明 |
| --- | --- |
| Docx | 飞书新版文档 |
| Wiki | 知识库文档 |
| Docs | 旧版文档 |

支持域名：`feishu.cn`、`larksuite.com`。

## 使用方法

1. 打开一个飞书 / Lark 文档页面。
2. 点击浏览器工具栏中的扩展图标，在弹窗中点击 **「导出 Markdown」**。
3. 等待处理完成，浏览器将自动下载 ZIP 文件。
4. 解压后即可获得 `文档标题.md` 及配套的 `images/` 目录。

> **提示**：若启用了 [AI 总结精简](#ai-总结精简可选)，需先在扩展设置页面中完成 API 配置。导出时，文档会先发送至你指定的大模型服务进行处理，处理完毕后再生成 ZIP 文件。

## AI 总结精简（可选）

在导出前可让大模型对文档内容进行总结与精简，特别适合长文档的要点提炼与去冗。  
该功能**默认关闭**，需在扩展设置页面手动开启并填写大模型 API。

### 配置项

在扩展的设置页面提供以下三项：

| 配置项 | 说明 | 示例 |
| --- | --- | --- |
| **API 地址** | 兼容 OpenAI Chat Completions 格式的接口地址 | `https://api.openai.com/v1/chat/completions` |
| **API 密钥** | 访问模型服务的鉴权密钥 | `sk-xxxxxxxx` |
| **模型名称** | 使用的模型标识 | `gpt-4o-mini`、`deepseek-chat` 等 |

> 兼容所有 **OpenAI Chat Completions** 风格的服务，如 OpenAI、DeepSeek、通义千问、Moonshot 等。

### 总结粒度

开启后可选择总结的粒度：

| 粒度 | 效果 |
| --- | --- |
| **精简摘要** | 将整篇文档提炼为简短要点，篇幅大幅压缩 |
| **逐段精简** | 保留原文结构，对每一段落分别进行精简与去冗余 |
| **仅去冗余** | 尽量保留原意，仅删除重复、啰嗦的表达 |

### 说明

- 所有配置信息保存在浏览器本地（`chrome.storage`），不上传至开发者服务器。
- 启用后，文档内容仅发送至你填写的**大模型服务商**，请自行确认其隐私政策。
- 提示词由扩展内置，随所选粒度自动切换，无需手动编写。

## 安装

### 从源码加载（开发模式）

确保已安装 Node.js，然后执行：

```bash
git clone <仓库地址>
cd feishu-wdh
npm install
npm run build
```

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择项目中的 `dist/` 目录。

## 技术栈

- **Manifest V3** – Chrome 扩展标准
- **Content Script** – 只读提取文档 DOM 与内容
- **Turndown**（或自研转换器） – HTML → Markdown
- **JSZip** – 客户端 ZIP 打包
- **FileSaver** – 触发浏览器下载

> 具体依赖以最终实现为准，优先使用最新稳定版本。

## 项目结构

```
feishu-wdh/
├── src/
│   ├── content/      # 内容脚本：滚动预加载 + 只读提取文档结构 + 抓图
│   ├── converter/    # Markdown 转换逻辑
│   ├── ai/           # 大模型调用与总结精简
│   ├── export/       # ZIP 打包、下载
│   ├── background/   # service worker：消息路由、编排导出流程
│   ├── offscreen/    # 离屏文档：Blob URL 触发下载（规避 SW 限制）
│   ├── shared/       # 跨模块类型、消息、存储封装
│   ├── options/      # 设置页面（API 配置、功能开关）
│   └── popup/        # 扩展弹窗 UI
├── public/
│   └── icons/        # 扩展图标
├── src/manifest.config.ts # 扩展清单（TS 形式）
└── dist/             # 构建产物
```

## 隐私说明

- 本扩展不包含自有服务器，**不会收集、留存任何用户数据**，亦不出售用户信息。
- 默认情况下，文档内容仅在本地浏览器中处理。
- **唯一例外**：当你主动开启「AI 总结精简」后，文档内容会发送给你自行配置的第三方大模型服务，该部分数据的处理受该服务商的隐私政策约束。
